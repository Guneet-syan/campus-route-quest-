How the algorithm works

  1. Set the start distance to 0 and all other distances to infinity.
  2. Repeatedly choose the unvisited node with the smallest known distance.
  3. Update its neighbours if travelling through the current node is shorter.
  4. Stop at the destination and follow parent links to reconstruct the route.

Why Dijkstra? All walkway distances are non-negative, and the algorithm finds an optimal shortest path. Breadth-first search is not suitable for unequal distances; A* can be faster on large maps if a useful heuristic is available.
